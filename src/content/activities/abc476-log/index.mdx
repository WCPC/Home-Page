### B問題

<details>

<summary>問題文を表示</summary>

<div style="background-color: #f5f5f5; padding: 15px; border-radius: 5px; border: 1px solid #ddd;">

### 問題文

$S$ は英小文字からなる長さ $N$ の文字列です。

$T$ は英小文字および `*` からなる長さ $N$ の文字列です。

$S$ が $T$ にマッチするとは、$T$ に含まれる `*` をそれぞれ好きな英小文字で置き換えることで $T$ を $S$ に一致させられることをいいます。

$S$ が $T$ にマッチするかどうかを判定してください。

### 制約

- $1 \leq N \leq 100$
- $S$ は英小文字からなる長さ $N$ の文字列
- $T$ は英小文字および `*` からなる長さ $N$ の文字列

### 入力

入力は以下の形式で標準入力から与えられる。

$N$<br/>
$S$<br/>
$T$

### 出力

$S$ が $T$ にマッチするならば `Yes` を、マッチしないならば `No` を $1$ 行で出力せよ。

</div>

</details>

$S$ ,$T$の長さが異なる場合は置き換えという操作をいくら行っても一致させることができないので `No` を出力し、それ以外の場合について考えます。
$S$ と $T$ の各文字について、異なっているかどうか、$T_i$ が `*` であるかどうかを見ていきます。
異なっており、かつ $T_i$ が `*` ではなければ、その時点で `No` を出力し、`No` を最後まで出力しなければ `Yes` を出力することで正解できます。

### C問題

<details>

<summary>問題文を表示</summary>

<div style="background-color: #f5f5f5; padding: 15px; border-radius: 5px; border: 1px solid #ddd;">

### 問題文

$3$ 以上の整数 $N$ と長さ $N$ の正整数列 $A=(A_1,A_2,\dots,A_N)$ が与えられます。

$k=3,4,\dots,N$ それぞれに対し以下の問題を解いてください：

    $A_1,A_2,\dots,A_k$ を降順に並べたとき、前から $3$ 番目にくる値を求めてください。

### 制約

- $3 \leq N \leq 5 \times 10^5$
- $1 \leq A_i \leq 10^9$
- 入力される値は全て整数

### 入力

入力は以下の形式で標準入力から与えられる。

$N$<br/>
$A_1$ $A_2$ $\dots$ $A_N$

### 出力

$N-2$ 行出力せよ。

$i$ 行目 $(1 \leq i \leq N-2)$ には $k=i+2$ とした時の答えを出力せよ。

</div>

</details>

**優先度付きキュー**を利用するのが最も簡単な解法だと思います。優先度付きキューを一つ用意し、最初の3文字を格納しておきます。
$k=3 ... N$ について、

- $k$ 番目の値を優先度付きキューに格納する
- 優先度付きキューから3個値を取り出す。
- 3回目に取り出した値だけを出力して、またすべて格納しなおす

という作業を繰り返すだけで解けます。わからなかった方は、各言語での優先度付きキューの使い方と仕様を調べておきましょう。

### 問題文

AtCoder 王国では、$1$ ドル紙幣と $K$ ドル紙幣の $2$ 種類の紙幣が流通しています。

AtCoder 王国にある J 社の全自動食堂では、デザートやドリンクが商品として売られています。

J 社の全自動食堂には、$N$ 個のデザートを売るデザート販売機と、$M$ 個のドリンクを売るドリンク販売機があります。 デザートには $1$ から $N$ までの、ドリンクには $1$ から $M$ までの番号が付けられています。

デザート $i$ の価格は $A_i$ ドル、ドリンク $j$ の価格は $B_j$ ドルです。

支払いに使う紙幣として、デザート販売機は $1$ ドル紙幣と $K$ ドル紙幣の両方を受け入れますが、ドリンク販売機は $K$ ドル紙幣しか受け入れません。 どちらの販売機も、お釣りはすべて $1$ ドル紙幣のみを使って返します。 同じ商品を $2$ 個以上買うことはできません。

高橋君は $1$ ドル紙幣 $X$ 枚と $K$ ドル紙幣 $Y$ 枚を持って J 社の全自動食堂にやってきました。

高橋君が手持ちの紙幣で買える商品の組合せにおいて、購入できる商品数の最大値を求めてください。

### 制約

- $1 \leq N \leq 2 \times 10^5$
- $1 \leq M \leq 2 \times 10^5$
- $2 \leq K \leq 10^9$
- $0 \leq X \leq 10^{15}$
- $0 \leq Y \leq 10^9$
- $1 \leq A_i \leq 10^9$ $(1 \leq i \leq N)$
- $1 \leq B_j \leq 10^9$ $(1 \leq j \leq M)$
- 入力される値はすべて整数

### 入力

入力は以下の形式で標準入力から与えられる。

$N$ $M$ $K$<br/>
$X$ $Y$<br/>
$A_1$ $\dots$ $A_N$<br/>
$B_1$ $\dots$ $B_M$

### 出力

答えを出力せよ。

</div>

</details>

したがって、ドリンクを買う数を全探索して、そのそれぞれについてデザートを何個買えるかを二分探索で高速に求めました。
前処理として累積和を用意しておかなければいけない点や問題文に使われている単語が多くて情報の処理が追いつかないといった点から、かなり時間を取られてしまいました。

### E問題

<details>

<summary>問題文を表示</summary>

<div style="background-color: #f5f5f5; padding: 15px; border-radius: 5px; border: 1px solid #ddd;">

### 問題文

$(1,2,\dots,N)$ の順列 $P=(P_1,P_2,\dots,P_N)$ と長さ $M$ の整数列 $L=(L_1,L_2,\dots,L_M)$, $R=(R_1,R_2,\dots,R_M)$ が与えられます。

この順列 $P$ に対し、$i=1,2,\dots,M$ の順に以下の操作を行います：

$P_{L_i},P_{L_i+1},\dots,P_{R_i}$ のうち、最小の値をもつ要素と最大の値をもつ要素の位置を入れ替える。

$M$ 回の操作が終わった後の $P$ の各要素を求めてください。

### 制約

- $2 \leq N \leq 2 \times 10^5$
- $1 \leq M \leq 2 \times 10^5$
- $P$ は $(1,2,\dots,N)$ の順列
- $1 \leq L_i < R_i \leq N$
- 入力される値は全て整数

### 入力

入力は以下の形式で標準入力から与えられる。

$N$ $M$<br/>
$P_1$ $P_2$ $\dots$ $P_N$<br/>
$L_1$ $R_1$<br/>
$L_2$ $R_2$<br/>
$\vdots$<br/>
$L_M$ $R_M$

### 出力

$M$ 回の操作が終わった後の $P$ の各要素を先頭から順に空白区切りで出力せよ。

</div>

</details>

ある区間の最大値や最小値を高速に求める必要がある、要素を更新する必要がある、ということからセグメント木を連想しました。このデータ構造を利用すればこの問題の「更新されるべき要素の値」が分かります。
それが分かれば、各要素の値とインデックスを紐づけておいてそれも同時に更新していけば解けることが分かります。
D問題よりも複雑でない、データ構造の知識があれば解ける問題でした。逆に落とさなくてよかったと思っています。
